# BF002.2 - Database Foundation

## Objective

Build the reusable database foundation that all repositories will rely on.

This sprint creates the generic database abstraction layer used throughout the application.

The goal is to avoid duplicated SQL logic and provide a reusable query system for every future module.

---

## Scope

Create the following structure:

app/Core/Database/

    DatabaseConnectionInterface.php
    QueryBuilderInterface.php
    BaseQueryBuilder.php
    PaginationResult.php
    Filter.php
    Sort.php

---

## DatabaseConnectionInterface

Create a database abstraction interface.

Required methods:

- connection(): PDO
- beginTransaction(): void
- commit(): void
- rollback(): void
- transaction(callable $callback)

---

## QueryBuilderInterface

Create a fluent query builder contract.

The builder should support:

- table()
- select()
- where()
- orWhere()
- whereIn()
- orderBy()
- limit()
- offset()
- first()
- get()
- insert()
- update()
- delete()

All query methods should support fluent chaining.

---

## BaseQueryBuilder

Implement QueryBuilderInterface.

Responsibilities:

- SQL generation
- Parameter binding
- Prepared statements
- Internal bindings management
- Generic query execution

Must NOT contain:

- Business logic
- Repository logic
- Module-specific logic

---

## PaginationResult

Create an immutable DTO representing paginated results.

Properties:

- data
- total
- page
- perPage
- lastPage

---

## Filter

Simple value object.

Properties:

- field
- operator
- value

---

## Sort

Simple value object.

Properties:

- field
- direction

---

## Coding Standards

- PHP 8+
- declare(strict_types=1);
- PSR-12
- Typed properties
- Typed parameters
- Typed return values
- PHPDoc
- Dependency Injection compatible

---

## Security Requirements

- Prepared statements only.
- Never concatenate user input directly into SQL.
- Store bindings separately from SQL.

---

## Acceptance Criteria

- All files compile successfully.
- QueryBuilder is reusable.
- Database layer is independent from business modules.
- Ready for BaseRepository.
- No business logic exists in this sprint.

---
